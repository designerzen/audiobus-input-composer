# T115 — Mixed-initiative musical arrangement

Family: **Interactive performance and adaptive timing**. Reviewed 24 November 2026. [Technique index](README.md).

## Mechanism

Distribute proposal, acceptance and execution authority between a person and an automated system.

## Proposed symbolic-music use

Allow autonomous bounded development while the person controls targets, locks, recall and rejection.

## Worked example or experiment setup

The system proposes a counterline; Conduct mode may enter it at a declared phrase boundary, while Suggest mode waits for acceptance.

## Time, emotion and energy

The wheel supplies expressive intention; energy supplies activity; future commitment boundaries make intervention predictable.

## Failure modes and practical limits

More automation can obscure the person’s contribution. Explanations must follow actual committed actions rather than invented narratives.

## Evaluation

Compare authority modes at equal material budgets and measure perceived control, contribution recognition and musical preference separately.

## AudioBus integration

Keep intended waiting, input latency and delivery latency separate. Test human control and contribution recognition alongside event correctness.

Produce resolved musical events before delivery. The [composer architecture](../11-composer-architecture.md), [Plutchik interface](../18-plutchik-interface.md) and [scheduling contract](../12-audiobus-events-and-scheduling.md) supply the shared context. This is research, not an implemented Input feature.
